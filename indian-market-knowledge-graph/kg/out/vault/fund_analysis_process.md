# Analysing Equity and Debt Mutual Funds

Equity - hygiene (AUM, objective, manager, benchmark) -> 3/5/10-yr rolling returns vs benchmark (avg/min/max) -> risk-return matrix (is excess return from extra risk?) -> capture ratios. Debt - align with goal and horizon, check portfolio credit quality, concentration, duration vs holding period, YTM as risk signal, AUM.
