# Equity Curve

Portfolio value normalised to Rs 100 over time (each holding compounding its daily returns at its weight); visualises performance, benchmark against Nifty; SD of its daily returns = portfolio volatility.

## Bot use
Core performance artefact for any strategy/portfolio; derive drawdown, volatility, Sharpe.
