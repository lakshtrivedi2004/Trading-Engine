# Linear Regression (for pairs)

Fit y = M*x + c (+ residual) between two price series; outputs slope (beta/hedge ratio), intercept, residuals, standard error (SD of residuals) and standard error of intercept.

## Formula
- **model**: `y = beta*x + c + e`
- **residual**: `actual_y - (beta*x + c)`
