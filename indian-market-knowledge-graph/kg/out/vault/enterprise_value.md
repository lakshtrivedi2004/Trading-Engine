# Enterprise Value and Equity Value

Rearranging the balance sheet - fixed assets = net debt + equity. Valuing the whole firm gives EV (discount FCFF at WACC); EV - debt + cash = equity value; divide by shares outstanding for fair value per share.

## Formula
- **net_debt**: `debt - cash`
- **equity_value**: `EV - debt + cash`
- **fair_price**: `equity_value / shares_outstanding`
