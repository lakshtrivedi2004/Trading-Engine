# M10 - Trading Systems

What a trading system is (quantified, backtestable process vs ad-hoc views), pair trading via ratio/spread/differential with z-score/density curve (Mark Whistler method), statistical arbitrage via linear regression, error ratio, cointegration/stationarity/ADF test and residual z-score trading with beta-neutral sizing and intercept caution, statistical futures calendar spreads, and cross-sectional momentum portfolios. (Volatility-based delta hedging was announced but not covered.)
