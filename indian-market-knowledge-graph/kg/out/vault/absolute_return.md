# Absolute Return

Percentage gain irrespective of time.

## Formula
- **absolute_return_pct**: `(end_value / start_value - 1) * 100`

## Conditions (machine rules)
- **use_when**: `holding period <= 1 year`

## Example
Buy 3030, sell 3550 => 17.16%.
