# Bonus Issue

Free shares from reserves in a fixed ratio (e.g. 2:1 = 2 new per 1 held); share count rises, price adjusts, value unchanged.

## Formula
- **post_price**: `pre_price * held / (held + bonus)`

## Facts
- Done to improve retail affordability/liquidity when share price is high.

## Example
1:1 - 100 sh @75 -> 200 sh @37.5; value 7,500 unchanged.
