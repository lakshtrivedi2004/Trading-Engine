# Model Layout and Format Hygiene

Same column = same year across every sheet; narrow index columns A, B and D; no gridlines; freeze panes; units stated (INR Cr); colour-code facts vs assumptions; break heavy line items into detail; do an annual-report recce first and use the latest year's format; never copy from third-party data vendors ('model suicide' = unstructured copy-paste).
